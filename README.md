# 보폭 · Bopok

부모님의 속도로 함께 떠나는 여행. 걷기·휴식·음식·경험 조건을 직접 확인하고 일정을 점검한 뒤, 수정 전후를 비교해 적용합니다. 큰 글씨 부모님 화면, 의견, 인쇄/PDF, 여행 보관함을 제공합니다.

Next.js + TypeScript + Zod, Vitest, Playwright. Node 24, npm, `package-lock.json`을 사용합니다.

```sh
npm ci
npm run dev
# 검증과 프로덕션 실행
npm run typecheck
npm test
npm run build
npm run start
# Chromium이 없으면 먼저 npx playwright install chromium
npm run test:e2e
```

쓰기 제한이 있는 클라우드에서는 `npm ci --cache /workspace/.npm-cache`를 사용합니다. 브라우저 검사는 자체 앱과 격리된 PostgreSQL/PGlite 서비스를 3000/3155 포트에 시작하므로 직접 실행한 서버를 먼저 종료합니다. 기존 서버나 실제 서비스 DB를 재사용하지 않습니다. 시스템 `/usr/bin/chromium` 또는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 지원합니다.

## 여행 자료

- **키 없는 시연:** 가상 솔바다 1~2일, 관광 15곳·식당 8곳·쉼터 7곳. 모든 시설·메뉴·경로 수치는 작성한 가상 데이터입니다. 실제 여행에 사용하지 않습니다.
- **실제 도시:** 전국 및 해외의 도시·국가를 입력해 Nominatim + Overpass의 OpenStreetMap 장소를 검색합니다. 한 도시 중심 반경 10km, 최대 30개 후보를 사용합니다. 모든 세계 장소를 수집하거나 접근성을 확인한 서비스라는 뜻은 아닙니다.
- **실제 경로:** openrouteservice가 제공한 도로 시간·거리만 사용합니다. 좌표 간 직선 거리로 동선을 계산하지 않습니다. 계단, 내부 보행, 좌석, 메뉴, 영업시간, 비용은 자료가 없으면 미확인으로 남습니다.
- 실제 장소 초안의 방문 40분·이동 20분은 편집용 배정 시간입니다. 실제 소요 시간이나 조건 충족값이 아닙니다. 경로를 조회해도 배정한 시간과 고정 일정은 유지하며 부족한 시간을 다시 경고합니다.

자료 출처·수집 시각·© OpenStreetMap 기여자/ODbL을 화면과 JSON에 남깁니다. 자료가 7일 이상 오래되면 다시 확인하도록 경고합니다. 실제 도시 검색은 서버 공유 캐시와 공개 앱 주소가 필요합니다. 연결 실패 시 가상 자료로 바꾸지 않습니다.

## 점검과 수정

조건 미입력은 미확인으로 유지하고 나이·활동 선호로 걷기 능력을 추정하지 않습니다. 필수 경험, 회피 조건, 고정 일정을 몰래 완화하지 않습니다. 모든 편집·제안에 같은 검증기를 적용합니다.

생성기는 방문 후보·순서·점심 위치와 고정 구간 주변 배치를 탐색합니다. 일당 최대 12,000개 평가와 16개 상태를 유지하는 제한된 탐색으로, 전역 최적해를 보장하지 않습니다. 고정 항목의 ID·장소·시작·종료를 보존합니다. 확인되지 않은 실제 시설 정보가 많으면 검증된 자동 추천 대신 확인 전 초안을 제공합니다.

## 보관과 가족 공유

브라우저 최근 여행 20개·입력 초안과 JSON 내보내기/가져오기는 계정 없이 동작합니다. JSON에는 여행 조건과 의견이 들어 있으며 공유 인증키는 포함하지 않습니다. 브라우저 삭제와 서버 삭제는 별도입니다.

Supabase를 연결하면 서버 여행 보관·복원과 다른 기기의 가족 의견을 지원합니다. 부모님 링크는 읽기/의견, 편집 링크는 일정 수정 권한을 갖습니다. 링크는 7일, 서버 여행은 마지막 저장 후 30일간 유효합니다. 소유자는 링크를 일괄 폐기할 수 있습니다. 서버 버전 비교로 오래된 수정안 덮어쓰기를 막고 의견을 병합합니다.

현재 소유자 인증은 서명한 익명 HttpOnly 쿠키입니다. 이메일 계정이 아니므로 쿠키를 삭제하면 소유자 접근 권한을 잃을 수 있습니다. JSON 백업과 비공개 편집 링크를 보관하세요. 링크를 공개 게시하면 해당 권한을 가진 접근이 가능해집니다.

## AI

OpenAI Responses API의 구조화 출력으로 자연어 조건을 추출하고, 기존 후보 ID·점검 코드에서 검토할 항목을 고릅니다. 설명은 기존 규칙 점검 메시지로 렌더링하며 AI가 새 시설 사실을 만들거나 시간표를 자동 변경하지 않습니다. 외부 전송 동의가 필요합니다. 키가 없으면 규칙 추출을 사용하고 AI 설명은 미연결 상태를 표시합니다.

서버 서명 세션, 영속 사용량 DB, 모델 단가, 일일 비용·토큰·요청 한도가 준비되지 않으면 유료 호출을 보내지 않습니다. 최악 사용량을 먼저 원자적으로 예약하며 실패 요청도 예약을 유지합니다. 실제 청구액이 아니라 보수적인 예약 금액입니다. 전달 IP 헤더로 이 제한을 우회할 수 없습니다.
