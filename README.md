# 보폭 · Bopok

부모님의 속도로 함께 떠나는 여행. 걷기·휴식·음식·경험 조건을 확인하고 일정을 점검한 뒤, 수정 전후를 비교해 적용합니다. 큰 글씨 부모님 화면, 가족 의견, 인쇄/PDF, 여행 보관함을 제공합니다.

Next.js + TypeScript + Zod, Vitest, Playwright. Node 24, npm, `package-lock.json`을 사용합니다. 현재 버전은 0.4.1입니다. [개선 결과와 남은 운영 연결](docs/RELEASE_READINESS.md)을 먼저 확인하세요.

```sh
npm ci
npm run dev
# 검증과 프로덕션 실행
npm run typecheck
npm test
npm run build
npm run start
# 브라우저 설치 후 별도로 실행
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
```

쓰기 제한이 있는 클라우드에서는 `npm ci --cache /workspace/.npm-cache`를 사용합니다. 브라우저 검사는 자체 앱과 격리된 PGlite SQL 서비스를 3000/3155 포트에 시작하므로 직접 실행한 서버를 먼저 종료합니다. 실제 서비스 DB를 사용하지 않습니다. 시스템 `/usr/bin/chromium` 또는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`도 지원합니다.

## 여행 자료와 범위

- **키 없는 시연:** 가상 솔바다 1~2일, 관광 15곳·식당 8곳·쉼터 7곳. 시설·메뉴·경로 수치는 가상 데이터이며 실제 여행에 사용하지 않습니다.
- **전국·해외 도시:** Nominatim + Overpass의 OpenStreetMap 장소를 검색합니다. 실제 여행은 최대 30일·10개 도시, 도시당 반경 1~50km·후보 10~200개, 전체 장소 2,000개를 지원합니다. 세계 모든 장소의 수집·시설 검증을 보장하지 않습니다.
- **시간대·예산:** 도시별 IANA 시간대와 현지 통화, 날짜별 도시 배정, 사용자가 기록한 도시 간 이동·숙박비를 점검합니다. 같은 도시 재방문과 날짜 변경선 전후의 현지 시작일을 지원합니다. 날짜에 맞는 이동 기록을 사용하며, 온종일 이동하는 날에는 관광·식사가 비었다는 경고를 표시하지 않습니다. 출처가 있는 7일 이내 환율만 환산에 사용합니다. 지원하지 않는 통화·누락 비용은 미확인으로 남습니다.
- **실제 경로:** openrouteservice의 도로 시간·거리, Google Routes의 대중교통 시간·거리를 사용합니다. 계단·내부 보행·좌석·운임·메뉴·영업시간은 자료가 없으면 미확인입니다. 대중교통에는 실제 출발 날짜와 도시 시간대를 적용합니다.
- 항공·숙박 예약, 자동 도시 간 운행표 수집은 제공하지 않습니다. 도시 간 이동은 출처와 출발·도착 시각을 직접 기록합니다.

실제 장소 초안의 방문 최대 40분·미확인 이동 20분은 편집용 배정 시간이며 실제 소요 시간이나 조건 충족값이 아닙니다. 자료 조회가 고정 일정과 배정 시간을 변경하지 않습니다. 자료 연결 실패는 오류·미확인으로 표시합니다.

출처·수집 시각·© OpenStreetMap 기여자/ODbL을 화면과 JSON에 남깁니다. 장소 자료는 7일, 경로는 하루가 지나면 다시 확인하도록 경고합니다. HTTPS 출처·확인 날짜를 붙인 사용자 시설 기록은 독립 검증 전까지 미확인입니다. 다른 계정의 지정 검토자가 승인한 기록만 서명 검증 후 독립 확인으로 취급하며, 수정·서명 위조·7일 경과 시 다시 미확인이 됩니다. 실제 도시 검색에는 서버 공유 캐시와 앱 주소가 필요합니다.

## 점검과 수정

미입력은 미확인으로 유지하고 나이·활동 선호로 걷기 능력을 추정하지 않습니다. 필수 경험·회피 조건·고정 일정은 모든 편집과 제안에서 같은 검증기로 점검합니다.

생성기는 방문 후보·순서·점심 위치와 고정 구간 주변 배치를 탐색합니다. 전체 최대 12,000개 평가와 16개 상태의 제한된 탐색이며 전역 최적해를 보장하지 않습니다. 날짜별 도시 후보와 고정 항목의 ID·장소·시작·종료를 보존합니다. 실제 자료가 부족하면 확인 전 초안을 제공하고, 대안이 없으면 이유를 표시합니다.

## 보관·계정·가족 공유

브라우저 최근 여행 20개·입력 초안과 8 MiB 이하 JSON 내보내기/가져오기는 계정 없이 동작합니다. 보관함의 일부 여행이 손상되어도 다른 정상 여행은 복원합니다. 저장 공간이 부족하면 현재 여행 저장과 보관함 갱신의 성공 여부를 구분해 표시합니다. JSON에는 조건·의견이 들어 있으며 공유 인증키는 포함하지 않습니다. 브라우저 삭제와 서버 삭제는 별도입니다.

서버 보관에는 Supabase 이메일 코드 로그인과 Turnstile 봇 확인을 사용합니다. 로그인하면 기존 익명 여행을 계정에 이전하고, 다른 기기에서도 같은 계정으로 복원합니다. 인증 쿠키는 HttpOnly이며 토큰을 갱신합니다. 익명 서버 모드는 별도로 허용한 시연·격리 환경에서 사용할 수 있습니다.

부모님 링크는 읽기/의견, 편집 링크는 일정 수정 권한을 갖습니다. 링크는 7일, 서버 여행은 마지막 저장 후 30일간 유효합니다. 소유자는 링크를 폐기할 수 있습니다. 서버 버전 비교로 오래된 수정안 덮어쓰기를 막고 최근 의견 30개를 병합합니다. 공개 게시한 링크의 권한은 링크를 가진 사람이 사용할 수 있습니다.

가족 공유 화면도 현지 출발 시각에 맞는 대중교통과 이동일 기록을 표시합니다. 로그아웃이나 여행 변경 중 도착한 이전 서버 응답은 적용하지 않습니다. 장소 갱신은 현재·이전 일정의 장소와 사용자 확인 기록을 보존하며, 좌표가 바뀐 경로는 다시 조회합니다. 미래 수집 시각·환율은 최신 근거로 취급하지 않습니다.

## AI와 운영

OpenAI Responses API의 구조화 출력으로 자연어 조건을 추출하고 기존 후보·점검 코드에서 검토할 항목을 고릅니다. 설명은 규칙 점검 근거를 사용하며 사용자 확인 후 반영합니다. 외부 전송 동의가 필요합니다. 키가 없으면 규칙 추출을 사용하고 AI 미연결 상태를 표시합니다.

계정·서버 서명·최신 DB·모델 단가·일일 비용/토큰/요청 한도가 없으면 유료 호출을 차단합니다. 최악 사용량을 먼저 원자적으로 예약하며 실패 요청도 예약을 유지합니다. 예약액은 실제 청구액이 아닙니다.

`/api/health`는 DB 스키마 12·계정·도로/대중교통·AI·봇·장소·환율·정리·검토자·알림·복원 상태를 검사하고 누락 시 503을 반환합니다. 공급자 키가 있어도 최근 24시간 내 해당 설정의 연결 검사가 성공하지 않으면 준비 상태를 통과하지 못합니다. `/ops`에서 개인정보를 제외한 최근 15분의 오류·지연 지표를 확인합니다. 운영 도메인 전환 전후 검사와 실패 시 이전 배포 복구, 앱 밖의 5분 주기 감시, 계정 데이터를 포함한 암호화 백업·격리 복원을 제공합니다. 실제 서비스 연결은 운영 계정·키·담당자 설정 후 검증해야 합니다.
