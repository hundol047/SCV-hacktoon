# 보폭 · Bopok

**부모님의 속도로, 함께 떠나는 여행.**

SVC Seoul AI 해커톤 시연용 MVP. 부모님이 직접 고른 걷기·휴식·음식·경험 조건으로 일정을 점검하고, 수정 전후를 비교한 뒤 적용합니다. 큰 글씨의 부모님 모드에서 의견을 기록하고 브라우저 인쇄/PDF 자료를 만들 수 있습니다.

구성은 Next.js App Router + TypeScript + Zod + Vitest + Playwright입니다. 스타일은 브랜드 레이아웃과 인쇄 규칙을 직접 관리하기 위해 Tailwind 대신 일반 CSS를 사용합니다.

**가상 시연 데이터 · 실제 여행에 사용하지 마세요.** 현재 국내 여행 형식의 **가상 솔바다 1~2일**만 지원합니다. 실데이터 모드는 없습니다. 관광 15곳, 식당 8곳, 쉼터 7곳 및 양방향 도보·택시 이동표를 사용합니다. 실제 지역의 접근성·메뉴·경로로 오해할 수 있는 자료를 사용하지 않습니다.

## 설치와 실행

Node.js 20.9 이상 (이 환경 검증: 24.19.0), npm. 패키지 관리자는 npm 하나이며 `package-lock.json`을 커밋합니다.

Windows PowerShell:

```powershell
git clone https://github.com/hundol047/SCV-hacktoon.git
cd SCV-hacktoon
git switch feat/bopok-mvp
npm ci
npm run dev
```

이미 체크아웃한 환경에서는 해당 폴더에서 `npm ci`, `npm run dev`를 실행합니다. 로컬 브라우저는 `http://localhost:3000`에서 엽니다. 개발 서버는 0.0.0.0에 바인딩됩니다. 이것은 배포 주소가 아닙니다.

```powershell
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`test:e2e`는 빌드된 앱을 대상으로 합니다. 먼저 `npm run build`를 실행하고 직접 실행한 3000번 포트 서버는 종료하세요. 테스트는 자체 서버를 자동 실행합니다. 기존 서버를 의도적으로 재사용할 때만 `BOPok_E2E_REUSE_SERVER=1`을 지정합니다. 빌드 후에는 기존 서버를 재시작해야 오래된 자산이 섞이지 않습니다. Linux의 `/usr/bin/chromium`이 존재하면 이를 사용하고, 그 외 환경에서는 Playwright 설치 브라우저를 사용합니다. 별도 브라우저 경로는 PowerShell에서 `$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH="C:\path\to\chrome.exe"`로 설정할 수 있습니다. 모바일 테스트는 Chromium의 iPhone 화면/터치 에뮬레이션이며 실제 iOS Safari 검증은 아닙니다.

프로덕션 모드 로컬 실행:

```powershell
npm run build
npm run start
```

쓰기 제한이 있는 클라우드 환경에서는 `npm ci --cache /workspace/.npm-cache`를 사용하세요. 시스템 Chromium이 없으면 `PLAYWRIGHT_BROWSERS_PATH`를 쓰기 가능한 경로로 설정하고 설치·테스트에서 동일하게 사용해야 합니다.

## 키 없이 시연하기

별도의 키와 환경 파일이 필요하지 않습니다. 홈 → **예시 여행 체험하기**로 시작하면 문제를 포함한 기존 일정과 부모님 조건이 로드됩니다. 수정안은 고정 화면이 아니라 후보 데이터 및 결정적 검증 엔진에서 생성됩니다. 자세한 흐름은 [시연 시나리오](docs/DEMO.md)에 있습니다.

조건을 모르면 비워 두고 ‘잘 모르겠어요’로 유지하세요. 시간 또는 거리만 입력할 수 있습니다. 활동 선호와 나이는 걷기 수치로 변환하지 않습니다. 회피 조건·필수 경험·예산 등을 몰래 낮추지 않으며 가능한 일정이 없으면 충돌을 표시합니다. 거리 조건이 없는 기본 시연은 수정 후에도 ‘정보 부족’이 남는 것이 정상입니다.

## 실제 AI로 전환

실제 서버 어댑터는 OpenAI **Responses API**, `text.format`의 JSON Schema 구조화 출력을 사용합니다. API 키와 모델이 없으면 외부 호출하지 않고 규칙 기반으로 동작합니다. 모델명은 사용자의 계정에서 사용할 수 있는 모델을 직접 지정해야 합니다.

```powershell
Copy-Item .env.example .env.local
# .env.local을 로컬에서 편집합니다. 실제 값은 Git에 추가하지 마세요.
npm run dev
```

| 변수                                  | 역할                                                                |
| ------------------------------------- | ------------------------------------------------------------------- |
| `BOPok_AI_KEY`                        | 선택 사항. 서버 전용 OpenAI 인증키                                  |
| `BOPok_AI_MODEL`                      | 선택 사항. 계정에서 사용 가능한 Responses API/구조화 출력 지원 모델 |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` | 선택 사항. 테스트용 Chromium 실행 파일 경로                         |

클라우드에서는 환경 설정의 보안 입력을 사용하고 비밀값을 채팅·소스·로그에 쓰지 마세요. `api.openai.com`으로 HTTPS 통신이 필요합니다. `NEXT_PUBLIC_*` 변수로 키를 설정하지 않습니다. 화면에서 외부 전송에 명시적으로 동의해야 실제 어댑터를 사용합니다. 설정이 있어도 동의하지 않으면 규칙 기반입니다.

AI는 **자연어 조건 추출과 확인 질문**에 사용합니다. 장소 선택, 일정 계산, 수정 설명 및 부모님 문장은 현재 규칙 기반입니다. AI가 최종 적합성을 판정하지 않습니다. 실패·12초 타임아웃·잘못된 구조/ID는 명시적인 실패 상태를 표시하고 같은 가상 모드의 규칙 기반 결과로 대체합니다. 재시도를 무한 반복하지 않습니다. 입력을 변경하면 이전 요청은 취소하고 버전 검사로 오래된 응답을 무시합니다. 추출 결과는 사용자가 확인하기 전 조건에 반영하지 않습니다.

이 작업의 실제 AI 키·모델은 제공되지 않았습니다. **실제 외부 AI 호출은 미검증**이며 테스트에서 어댑터의 정상·오류·타임아웃 응답을 모의 검증합니다. 공식 참조: [Next.js 설치](https://nextjs.org/docs/app/getting-started/installation), [OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create), [공식 SDK 요청 타입](https://github.com/openai/openai-node/blob/master/src/resources/responses/responses.ts). 구현 때 공식 문서 GitHub 원문과 npm 패키지 메타데이터를 확인했습니다.

## 데이터와 엔진

```
src/components/          화면, 단계 입력, 타임라인, 편집, 부모님 모드
src/domain/schema.ts     Zod 입력·저장 스키마, 도메인 타입, 분 단위 시간
src/data/demo.ts         가상 장소 30곳, 이동표, 필드별 가상 근거 ID
src/domain/validate.ts   조건·일정 검증 (순수 함수)
src/domain/engine.ts     생성·수정·적용·이력·텍스트 파싱 (순수 함수)
src/adapters/ai.ts       공급자 인터페이스, 규칙/실제 어댑터, 출력 검증
src/adapters/storage.ts  버전 1 브라우저 저장소 어댑터
src/app/api/conditions/  서버 전용 AI 요청 경계
tests/                   단위 테스트 및 데스크톱·모바일 E2E
```

수치 기준은 시간=분, 거리=m, 비용=원, 표시 시간대=Asia/Seoul입니다. 장소 간 도보와 내부 보행을 누적합니다. 확인된 좌석이 있고 사용자가 정한 최소 휴식 시간 이상인 휴식 구간만 보행 누적을 초기화합니다. 식사·택시·빈 시간은 자동으로 휴식이라 가정하지 않습니다. 너무 짧은 휴식, 경로 누락, 계단 미확인, 메뉴 미확인은 경고를 남깁니다. 가상 메뉴 회피 검사는 시연에 정의된 ‘매운 음식/순한 음식/지역 음식/죽’ 범주만 지원하며 그 밖의 회피 음식은 확인 불가입니다. 여행의 안전 보증 기능은 아닙니다.

수정 엔진은 확인된 후보에서 체류와 이동 사이의 좌석 휴식을 넣어 순서를 생성하고 같은 조건으로 재검증합니다. ‘충족 / 위반 / 정보 부족 / 충돌’을 구분하며 위반·충돌이 남은 수정안은 적용을 막습니다. 정보 부족은 사용자에게 그대로 알리고 적용 여부를 선택하게 합니다. 부모님 의견은 기존 일정을 즉시 바꾸지 않고 새 수정안을 만드는 입력으로 사용합니다.

고정 구간은 보존합니다. **고정 일정 주변의 자동 재배치는 아직 지원하지 않으며**, 고정 항목이 있는 경우 원래 일정을 유지하고 직접 편집을 안내합니다. 직접 편집 화면에서 고정을 명시적으로 해제할 수 있습니다. 적용과 수동 편집의 이전 일정은 최대 20개까지 되돌릴 수 있습니다.

실데이터로 교체하려면 별도의 코딩 작업으로 데이터 어댑터/모드/스키마를 추가해야 합니다. `demo.ts`의 실제 장소 이름만 바꾸어 사용하면 안 됩니다. 공급자의 이용조건·출처·수집 시각, 필드별 접근성·운영시간·메뉴 근거, 실제 경로 소요 시간, 내부 보행을 확보하고 null은 미확인으로 보존하세요. 가상/실제 모드의 저장 키·데이터 집합을 분리하고 혼합 거절 테스트를 유지해야 합니다. 직선거리를 실제 도보 거리로 대체하지 않습니다.

## 저장 범위와 개인정보

작성 중인 조건과 마지막으로 생성한 여행 한 개, 수정 이력, 부모님 의견을 **같은 브라우저/출처의 localStorage**에 저장합니다. 다른 기기 실시간 공유·회원 계정·가족 공유 링크는 없습니다. 자연어 원문과 AI 동의는 저장하지 않습니다. 필드 입력과 시간표는 버전/스키마로 검증하며 손상·용량·권한 오류는 안내하고 앱 흐름을 유지합니다. 하단 **내 여행 데이터 삭제**는 두 저장 키와 화면 상태를 지웁니다. 브라우저 저장소 삭제로도 지울 수 있습니다.

이름·나이·질병명·진료기록·복약·주민등록번호를 요구하는 필드는 없습니다. 자연어에는 여행 취향과 걷기·휴식 조건만 쓰세요. 서버는 명백한 의료/식별정보 문구를 거절하지만 모든 개인정보를 자동 탐지한다고 보장하지 않습니다. 서버 파일시스템·로그에 사용자 원문을 저장하지 않습니다.

외부 AI 사용에 동의하면 입력한 자연어 여행 조건을 조건 추출 목적으로 OpenAI에 전송합니다. 응답 저장을 요청하지 않는 `store:false`를 사용하지만 공급자의 처리 정책까지 보증하지는 않습니다. 개인·의료 정보는 입력하지 마세요. 인증키는 서버 환경에만 있으며 클라이언트에 전달하지 않습니다. 요청은 최대 1,800자, 프로세스별 1분 10회, 타임아웃 12초입니다. 운영 배포 전 분산 요청 제한·신뢰 가능한 클라이언트 식별·인증·비용 관리는 별도 구현해야 합니다.

## 접근성과 출력

모바일 우선 반응형, 입력 레이블, 키보드 포커스, 본문 바로가기, 오류 알림을 제공합니다. 부모님 주요 본문 20px 이상, 의견 버튼 58px입니다. 색상과 함께 상태 이름·문장으로 문제를 구분합니다. 동작 축소 설정을 존중합니다. 화면의 일러스트는 직접 작성한 SVG이며 외부 사진이 없습니다.

부모님 모드의 **인쇄 / PDF 저장**은 브라우저 인쇄 대화상자를 엽니다. ‘PDF로 저장’을 사용하세요. 메뉴·의견·편집 버튼은 인쇄에서 숨겨지고 가상 데이터 경고는 남습니다. 일정 항목은 페이지 중간에서 잘리지 않도록 설정합니다. 서버 PDF 생성이나 다른 기기 공유를 의미하지 않습니다.

## 검증 및 한계

- 단위 테스트: 연속 보행 시간/거리 경계, 내부 보행 합산, 충분/불충분 휴식, 계단·경로·메뉴 미확인, 시간 겹침·역순·이동 부족, 고정 보존, 불가능한 조건, 수정/되돌리기, 저장 오류, AI JSON/ID/타임아웃/키 없음.
- 브라우저: 새 여행과 기존 일정, 비교·적용·수동 수정, 부모님 의견, 복원·삭제, 인쇄 CSS/print 호출, 오류/404, 모바일 오버플로 및 키보드 이동.
- 실제 데이터 연동·실제 AI 연결·외부 배포·새 클라우드 환경 복원은 미검증입니다. 여행 예약·GPS·의료 진단·안전 보증·공동 편집은 범위 밖입니다.
- 인쇄 CSS와 브라우저 PDF 렌더링은 검사하되, 모든 프린터·실제 iOS/Android 기기·스크린리더의 실기 검증은 미완료입니다.
- 현재는 대표 일정을 조합하는 MVP 생성기이며 전체 후보의 전역 최적해나 모든 입력에 대한 최적 일정 탐색을 보장하지 않습니다. 음식·혼잡 등 실제 정보는 없습니다.

현재 실행 결과·Git 상태는 완료 보고를 확인하세요. 명령을 실행하지 않고 테스트 통과나 배포를 주장하지 않습니다.
