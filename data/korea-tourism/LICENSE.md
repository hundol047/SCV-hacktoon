`manifest.json` identifies the source, regional coverage, upstream timestamp,
retrieval times, query version, category counts, missing fields and SHA-256 digest.
The collector preserves source object identifiers; different OSM objects may
represent the same physical venue. The downloadable dataset includes unnamed objects.

This is the selected OSM classifications within 17 geographic divisions based on
the existing province/metropolitan boundaries, not a census of every actual
Korean tourism venue. Historic boundaries are explicitly marked in the coverage.
Images, private data, guessed menus/prices/accessibility and live festival facts
are not included. Redistribution of this database retains ODbL attribution.

Optional TourAPI basic files are a separate source, currently not collected or
served by the application. Consult that provider's applicable terms before
redistribution; they do not inherit this OSM database license.
