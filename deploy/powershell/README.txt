여행잇 — 숙소·비용·날짜별 계획·실시간 공유 업데이트

기존 EC2 설정은 유지합니다. ZIP에 API 키나 서버 비밀값은 포함하지 않습니다.

1. Supabase SQL Editor에서 013_group_votes.sql, 014_live_plans.sql을 순서대로
   실행하세요. 이미 실행한 파일을 다시 실행해도 테이블 데이터는 유지됩니다.
   013은 장소 의견, 014는 최신 일정 공유·변경안 투표 기능에 필요합니다.
2. ZIP 전체를 푼 뒤 Windows PowerShell에서 실행하세요:
   powershell -ExecutionPolicy Bypass -File .\Deploy-Yeohaengit.ps1 -KeyPath "$HOME\hackathon-e5-t02.pem"
3. http://52.65.9.104:8000/ 을 열고 Ctrl+F5로 새로고침하세요.

Linux 명령(bash, sudo, WORK_DIR=$(...))을 Windows PowerShell에 직접 입력하지 마세요.
서버에 이미 SSH로 접속한 상태라면 소스 압축을 푼 폴더에서:
   bash deploy-server.sh 8000

이번 변경:
- 선택한 숙소의 도로 이동·체크인·다음 날 출발과 입력한 숙박 합계 반영
- 날짜별 10분 단위 시작·종료 시각, 귀가 제한 반영
- 식사·입장·교통 등 예상 단가와 할인 조건 저장, 입장료 할인권 직접 등록
- 비용 절약 / 이동 절약 / 여유 코스의 도로·금액 비교 후 적용
- 새 공유 링크는 15초 간격 갱신, 변경안은 동행자 과반 찬성 후 작성자 확정
- 기존 사본 공유 링크와 캘린더 내보내기 유지

필요한 기존 설정:
/etc/yeohaengit/server.env 의 AWS 리전, EC2 IAM 인스턴스 역할, Supabase RPC,
세션 설정, 관광정보 API 키를 유지하세요. AWS 정적 키를 ZIP이나 화면에 넣지 마세요.
설치 스크립트는 새 이미지에서 Bedrock 호출을 검증한 후 기존 컨테이너를 교체합니다.

범위:
- 도로 시간은 실시간 교통 정체를 반영하지 않습니다.
- 숙소 가격은 직접 입력값 또는 계획용 예상값입니다. 객실 재고·최저가 API는 미연동입니다.
- 공식 지역별 할인 목록과 확인된 조건을 제공하며 전국의 모든 쿠폰을 자동 수집하지 않습니다.
- 공유 링크 보유자에게 출발지·숙소·비용이 보입니다. 링크는 30일간 유효합니다.
- 공유 작성 권한은 작성 브라우저 세션에 연결됩니다. 투표는 브라우저별 1표입니다.
- 이번 ZIP은 웹 서버 업데이트입니다. 별도 APK를 새로 만든 패키지가 아닙니다.
