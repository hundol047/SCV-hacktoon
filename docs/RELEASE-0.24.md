# 현재 위치로 출발지 입력

- 출발 지역 옆 현재 위치 버튼을 눌렀을 때만 브라우저 위치 권한을 요청합니다.
- 주소 자동 입력 후 실제 기기 좌표를 일정 생성과 출발지 주변 터미널·역 조회에 사용합니다.
- 주소 조회 장애 시에도 현재 위치 좌표를 사용할 수 있습니다. 위치 요청 중 직접 입력하면 이전 요청 결과가 입력을 덮어쓰지 않습니다.
- 국내 출발지 지원. 위치 거절·시간 초과·지원하지 않는 브라우저는 직접 입력으로 안내합니다.
- 휴대폰 위치 접근은 HTTPS가 필요합니다. 기존 HTTP IP 배포에서는 안내만 표시하며, 서버 배포와 별도로 HTTPS 설정이 필요합니다.
- 역지오코딩에는 OpenStreetMap Nominatim을 사용합니다. 좌표는 이 조회를 위해 전송되며 역지오코딩 서버 캐시에는 저장하지 않습니다. 생성한 일정의 출발 좌표 저장·공유는 기존 일정 기능을 따릅니다.
