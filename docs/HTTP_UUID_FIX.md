# HTTP 일정 생성 오류 수정

사용자 화면의 `crypto.randomUUID는 함수가 아닙니다` 오류는 HTTP 미리보기에서
HTTPS 전용 randomUUID를 호출한 것이 원인입니다. AI 응답과 일정 계산 후 ID를
생성하는 단계에서 예외가 발생해 저장·결과 화면 전환이 중단됐습니다.

공통 UUID 함수를 추가했습니다. randomUUID가 없으면 HTTP에서도 사용할 수 있는
crypto.getRandomValues로 UUID v4를 생성합니다. Math.random이나 고정 ID는 사용하지
않습니다. 간편 일정·예시 여행·행사·Android 요청 ID 등 직접 호출한 모든 곳에 적용했습니다.

로그인 글자의 배경과 테두리를 제거했습니다. 눌렀을 때만 입력 패널이 열립니다.
사용자 화면의 Amazon Bedrock, API 키 등의 구현 설명은 제거하거나 여행 안내로
교체했습니다. 모델·IAM 역할·응답 검증·실험 모드의 사용량 한도는 유지합니다.

검증: UUID와 코스 응답 단위 테스트 5개, 데스크톱/모바일 브라우저 6개 통과.
브라우저에서 randomUUID를 제거한 상태로 강릉 3일치 모의 AI 응답을 받아 결과
표시·저장·새로고침 후 보존까지 확인했습니다. Android 브리지도 모의 서버로 검사했습니다.
웹 빌드 및 Android 0.15.1(코드 17) 빌드·서명 검증 완료.
실제 EC2에 새 버전을 배포하고 실물 기기에서 확인하는 과정은 사용자 실행이 필요합니다.
