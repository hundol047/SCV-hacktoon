# 0.17.1 — 영주 지역 판별과 여러 날 후보 배분 수정

재현 원인: 지역 미지정 `영주` 검색은 첫 문자열 일치 결과인 인천 `공영주차장`의 시도 코드를 채택했습니다. 전체 검색 결과의 지역별 증거를 집계하고 주소의 시·군·구 일치에 가중치를 부여하도록 웹/Android를 수정했습니다. 기존 영주 자료만으로도 3일의 새 관광지를 배분하는 회귀 테스트를 추가했습니다. 앞선 날의 3곳 선택 때문에 마지막 날 1곳만 남지 않도록 남은 날짜당 최소 2곳을 확보합니다. 기존 날씨·시설·휴무 검증은 유지됩니다.

웹 지역 후보 조회는 서버에 TourAPI 키가 있으면 지역 코드를 확인한 뒤 `areaCode2`에서 입력한 시·군·구를 정확히 찾아 `areaBasedList2`의 관광지(12), 문화시설(14), 음식점(39)을 병렬로 보완합니다. 각 유형 최대 100건, 최종 후보 최대 200곳이며 이름 중복은 기존 자료보다 공식 자료를 우선합니다. 전국 49,677건 전체를 내려받지 않습니다. 8초 제한/6시간 캐시/프로세스당 하루 최대 2,000요청으로 제한합니다. 인증키는 서버에만 존재하며 오류 시 기존 후보를 사용합니다. Android 내장 목록은 지역 판별/후보 배분 수정이 반영되며 공식 후보 목록 조회는 현재 웹 경로에 적용됩니다.

공식 목록으로 추가된 장소에는 주소/전화가 포함되며 상세 운영시간을 모두 보장하지 않습니다. 사진은 이번 변경에 포함하지 않습니다. TourAPI 장소와 OSM 장소를 함께 보내도 기존 OSM 상세정보 조회가 전체 거절되지 않도록 요청 형식을 확장했습니다.

검증: 실제 내장 자료에서 영주→경북 및 3일 코스 생성 재현, 공식 시군구 코드/유형별 조회·좌표 검증·캐시·키 비노출·공급자 실패 fallback 테스트. 실제 EC2의 Bedrock 생성과 관광공사 공식 시군구 응답은 이 환경에서 검증하지 않았습니다.
