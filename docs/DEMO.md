# 보폭 해커톤 시연 · 3~5분

준비: `npm ci`, `npm run build`, `npm run start`. 키 없이 진행할 수 있습니다. 이전 기록을 지우려면 홈 하단 ‘내 여행 데이터 삭제’를 누르세요.

1. 홈에서 **예시 여행 체험하기**. 모든 지역·장소·시설·메뉴·경로가 가상임을 먼저 설명합니다.
2. 조건 카드를 확인합니다: 한 번에 걷기 20분, 휴식 60분마다 20분, 계단 피하기, 매운 음식 피하기, 바다 보기, 점심 13:30 이전. 거리는 모르므로 ‘정보 부족’입니다.
3. **일정 점검하기**. 도보 12분+내부 보행 28분=40분, 계단이 있는 가상 전망길, 5분짜리 부족한 휴식, 늦은 매운 점심을 각각 관련 구간과 연결해 보여 줍니다.
4. **부모님 조건에 맞게 수정하기**. 원래/제안 일정을 비교합니다. 바다 감상은 유지하고, 가상 푸른창 바다쉼터 등 계단 없는 후보·택시·좌석 휴식·이른 점심으로 재배치합니다. 계산은 규칙 기반이라고 설명합니다.
5. 남은 확인 사항을 읽습니다. 입력하지 않은 거리 조건은 ‘정보 부족’으로 남습니다. 충족이라고 표시하지 않습니다.
6. **수정안 적용**. 새 일정과 검증 결과를 확인합니다. 필요하면 ‘직접 수정’에서 시간을 바꾸어 경고가 달라지는 것을 보여 주고 ‘이전 일정으로 되돌리기’로 복원합니다.
7. **부모님 모드**. 큰 글씨, 이동/걷기, 식사, 쉬는 시간, 출발 전 확인 사항을 읽습니다.
8. **쉬는 시간을 늘려 주세요**. 현재 일정은 그대로입니다. 자녀용 화면으로 돌아가 **의견을 반영한 수정안 보기**를 눌러 30분 휴식 제안과 재점검을 확인하고 적용합니다.
9. 부모님 모드에서 **인쇄 / PDF 저장**. 인쇄 미리보기에서 메뉴와 의견 버튼은 숨겨지고 가상 경고가 남는지 확인합니다. 브라우저의 ‘PDF로 저장’을 사용할 수 있습니다.
10. 새로고침 후 홈의 ‘이어서 보기’로 복원되는 것을 확인합니다. 키 없는 환경의 보관은 해당 브라우저에 한정됨을 설명합니다. 서버 연결 환경의 가족 공유는 아래 별도 흐름을 사용합니다.

조건 변화 시연: 새 여행에서 한 번에 걷기 1분을 설정하면 현재 가상 관광 후보로는 만들 수 없다고 표시합니다. 조건을 몰래 20분으로 바꾸지 않습니다. 거리·휴식 등을 채우면 결과의 정보 부족 항목이 실제로 달라집니다.

AI 시연: ‘말로 적는 편이 더 편한가요?’에 “한 번에 20분 걷고 싶고 바다를 보고 싶어요. 매운 음식은 피하고 싶어요.”를 입력합니다. 키가 없으면 ‘규칙 기반 시연’이 표시됩니다. 추출 결과를 확인한 뒤에만 카드에 반영합니다. 실제 AI 연결 완료라고 말하지 마세요.

## 실제 도시와 가족 공유 확장

전국·해외 실제 도시는 여행 기본 정보의 데이터 모드를 바꾼 뒤 도시·국가를 입력합니다. 서버 캐시와 공개 앱 주소가 연결된 환경이 필요합니다. 미확인 시설이 많은 실제 자료는 확인 전 초안이며 배정한 시간은 실제 이동 시간과 구분합니다. 실제 경로 버튼은 서버 경로 키가 연결된 환경에서 사용할 수 있습니다. 미확인·하루 지난 경로와 모든 경로 재조회, 장소 자료 새로고침을 제공합니다. 시설·메뉴 확인 기록은 사용자 기록으로 표시합니다.

서버 연결 후 결과 화면에서 여행 저장 → 부모님 확인 링크 생성 → 다른 브라우저에서 링크 열기 → 의견 남기기 → 자녀 화면에서 의견 확인 → 제안 비교 순서로 진행합니다. 부모님 링크로는 일정 편집이 불가능합니다. 편집 링크, 공유 폐기, 버전 충돌, 여행 JSON 백업도 별도로 시연할 수 있습니다. 서버 소유권 복구에서 복구 키를 발급하고 안전하게 보관한 뒤 쿠키를 지워 복구를 시연할 수 있습니다. JSON 백업도 별도로 보관하세요.

AI 검토 설명은 별도의 외부 전송 동의와 서버 API·비용 한도 설정이 필요합니다. 연결되지 않은 환경에서는 규칙 점검을 사용하고 실제 AI 응답으로 소개하지 않습니다.
