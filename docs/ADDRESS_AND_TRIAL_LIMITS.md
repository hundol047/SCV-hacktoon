# 주소 검색과 실험 한도 (Android 0.16.1)

출발지 검색을 관광지 목록 검색에서 별도 Nominatim 주소/POI 검색으로 변경했습니다.
한국 내 학교명·장소명·도로명주소를 명시적 생성 동작 시 조회합니다. 자동완성이나
타이핑마다 조회하지 않습니다. 공유 DB 캐시와 Nominatim 요청 간격 잠금을 사용합니다.
복수 후보는 주소와 이름을 표시하고 사용자가 고르기 전 AI를 호출하지 않습니다.
검색 결과가 없거나 공급자 오류가 나면 도시 중심 좌표로 임의 대체하지 않습니다.
선택한 좌표를 AI와 첫날 코스 정렬·외부 길찾기에 사용합니다. 실제 검색 공급자에
해당 학교/주소 데이터가 없는 경우에는 시·구를 포함한 주소로 다시 검색해야 합니다.

--experiment-ai 배포 옵션은 기존 설정을 비공개 백업한 후 익명 AI 사용과 다음
최소 한도를 설정합니다. 기존 값이 더 높으면 유지하며 사용량 테이블은 지우지 않습니다.
- 계산 예산: 하루 10 USD
- 요청: 하루 100회
- 토큰 예약: 하루 1,000,000개
단가 10/30은 기존 임시 추정값을 그대로 사용합니다. 실제 청구액 상한 보장이 아닙니다.
현재 예약은 호출당 0.228 USD이므로 예산 한도가 먼저 적용되어 약 43회까지입니다.
요청 거절 시 사용량은 증가하지 않으며, 전송된 호출의 실패는 비용 발생 가능성이
있어 예약을 임의 환불하지 않습니다. 거절 후 기본 추천을 했다는 잘못된 문구는 제거했습니다.

큰 이용 안내 패널·자료 기준일·설명 문구를 없앴습니다. 필수 라이선스는 작은 ©를
누르면 대화상자로 표시됩니다.

검증: 주소/캐시/선택/공급자 실패/글로벌 한도 단위 테스트 7개, 데스크톱·모바일
브라우저 검사 14개, 설정 백업·키 보존·재실행 검사, 웹 빌드와 APK 빌드·서명 검사.
주소 및 AI 응답은 테스트에서 모의 응답을 사용했습니다. 이 환경에서 Nominatim의
판교고등학교 실조회는 프록시 403으로 차단되어 실제 결과 수신은 미검증입니다.
서버 배포 후 해당 주소 검색과 새 실험 한도 적용을 확인해야 합니다.
