# 여행잇 0.15.0

## 화면 변경

상단 여행 만들기와 지역 맞춤/택시/자가용 시작이 모두 한 화면으로 연결됩니다.
여행 입력은 전체 합계 5개입니다: 지역, 날짜, 기간, 이동 수단, 취향.
기존 걷기·휴식, 여행 취향, 조건 확인, 여행 정보의 4단계 입력과 추가 상세 입력을 제거했습니다.
지역 검색 후 AI 일정 생성, 응답 검증, 실패 시 기존 일정 보존은 유지합니다.

## 한국 관광지 사진

해운대(frakorea, CC BY 2.0), 불국사(martinroell, CC BY-SA 2.0), 성산일출봉(Korea.net / Korean Culture and Information Service, CC BY-SA 2.0) 사진을 온라인으로 표시합니다.
각 출처 페이지에서 작성자와 라이선스를 확인했습니다. 정확한 원본·출처·허가 링크는 public/images/korea/online.json에 있습니다.
화면에 관광지명·지역·작성자·출처·라이선스를 표시하고 다운로드 버튼은 제공하지 않습니다.
첫 화면 대표 사진은 한국 시간 자정 기준으로 순환합니다. 갤러리에는 3장을 함께 표시합니다.
Android에서도 Wikimedia 사진 호스트의 HTTPS JPG만 추가 허용합니다.

실행 환경 네트워크 정책이 이미지 바이너리 다운로드를 차단하여 온라인 사진의 실제 로딩은 검증하지 못했습니다.
로컬 manifest는 비어 있으며, 365장 오프라인 내장 요구사항은 아직 충족하지 못했습니다.
사진을 보려면 사용자 기기의 인터넷 연결과 해당 호스트 접근이 필요합니다.

## 검증과 배포 범위

웹 프로덕션 빌드, TypeScript, 단위 테스트 193개, Android APK 빌드·서명 검증, Docker 이미지 빌드를 완료했습니다.
데스크톱/모바일 Chromium 브라우저 검사 12개를 통과했습니다. 입력 수·시작 버튼·출처 링크와 AI 성공/실패·저장 보존·사진 보관함·Android 서버 브리지를 검사합니다.
AI 성공 테스트는 모의 응답이며 실제 Bedrock 호출이 아닙니다. 사진 테스트는 URL과 표시 정보만 검사합니다.
APK는 버전 코드 16이며 0.14.0과 동일한 미리보기 키로 서명했습니다.
PowerShell ZIP에는 최신 웹 소스와 기존 EC2 IAM/Bedrock 검증 배포 스크립트가 포함됩니다.

실제 EC2 배포/역할 인증/Bedrock, 실물 Android, Windows PowerShell은 이번 환경에서 실행하지 못했습니다.
이전에 보고된 Server deployment failed 메시지는 최종 실패 통지이며 서버 쪽 근본 원인은 아직 확인되지 않았습니다.
웹 화면 변경은 새 ZIP으로 서버 배포가 성공한 뒤 적용됩니다.
기존 /workspace/SCV-hacktoon은 변경하지 않았습니다.
