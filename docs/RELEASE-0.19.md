# 여행잇 0.19 — 간결한 추천과 오전·오후 일정

- 대체 관광지 추천의 빈 비교표, ‘미확인’ 개수/목록 및 반복 안내를 제거했습니다. 장소명, 취향 공통점, 주소, 지도, 교체 버튼을 제공합니다. 검증 자체는 그대로 유지하며 실제 위반/충돌이 있는 경우 안내합니다.
- ‘떠나기 전에 확인’은 운영시간·예약·이동편 한 줄로 줄였습니다. 실제 충돌/위반은 중복을 제거한 별도 펼침 항목으로 유지합니다. unknown 상태를 충족 상태로 바꾸지는 않습니다.
- 간편 입력에 ‘여행 시간대’를 추가했습니다. 오전 09:00~18:30, 오후 13:00~19:00이 매 여행일에 적용됩니다. 오전은 관광지 최대 4곳, 오후는 최대 3곳을 요청하며 다음 날짜의 최소 후보를 보존합니다. 기존 저장 일정은 자동 변경하지 않습니다.
- 이동·식사·관광·휴식을 포함해 종료 시간까지 배분합니다. 관광은 한 곳당 최대 180분이며 부족한 후보나 남는 시간은 실제 장소의 ‘자유 시간’으로 구분합니다. 오전은 점심과 별도 식당 후보가 있으면 저녁, 오후는 저녁을 배치합니다. 식당이 없는 경우 새 식당을 꾸며 넣지 않습니다. 표시 시간은 배정한 일정이며 실제 영업시간/교통상황을 보장하지 않습니다.
- 일정 표시에서 시작·종료 시간을 함께 보여줍니다. 공유 사본/ICS에도 시간대와 일정 라벨을 보존합니다. 기존 시간대 선택 없는 일정의 생성 방식은 유지합니다.
- 항공권(네이버 항공권), 제주·국내 배편(가보고 싶은 섬), 해외 배편(Direct Ferries), 시외버스 티머니, 코레일 예약 사이트 링크를 제공합니다. 실제 운항 노선/가격/좌석은 해당 사이트에서 선택·확인하며 앱이 자동으로 예약하거나 결제하지 않습니다. 해외 일정 생성 범위를 새로 확대하는 변경은 아닙니다.
- 제주-육지 및 해외 일정에는 지상 버스 경로 대신 공항·항구 안내를 표시합니다. 항공/선박 도착 시각에 맞춰 시간대를 선택해야 하며 탑승 시간을 임의 생성하지 않습니다.

검증: 오전/오후 시작·종료, 관광·식사·휴식 중복 없음, 3일 일정 결합, 자유시간 구분, 공유 데이터 보존, 제주/해외 안내 분기 단위 테스트. PC/모바일 브라우저에서 시간대 선택, 예약 링크, 비교표 제거, 짧은 안내, 공유 및 APK 웹 자산 회귀 테스트. 실제 EC2 AI 호출·운항 좌석/시간표·Android 실기기 검증은 수행하지 않았습니다.
