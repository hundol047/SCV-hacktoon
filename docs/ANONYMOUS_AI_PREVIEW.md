# 로그인 없는 AI 실험

`BOPok_AI_ALLOW_ANONYMOUS=true`를 설정하면 코스 추천·대체 관광지·홍보 콘텐츠의
AI 호출을 로그인 없이 허용합니다. 기본값은 비활성입니다. Supabase의 원자적
사용량 예약, 서버 전체 일일 요청/토큰/비용 한도, 출처 검사와 모델 응답 검증은
유지합니다. 로그인 사용자도 같은 서버 전체 한도를 공유합니다.
서버 저장·공유 등 기존 계정 권한 설정은 바꾸지 않습니다.
현재 단가 10/30은 운영자가 입력한 임시 계산값이며 실제 청구액 상한을 보장하지 않습니다.

ZIP을 풀고 소스 압축을 해제한 뒤 서버에서 실행:

```bash
bash deploy-server.sh 8000 --anonymous-ai
```

기존 root 전용 server.env를 백업한 뒤 AI 실험 설정 한 줄만 추가합니다.
기존 키·로그인·비용 한도를 보존합니다. 새 컨테이너 시작 전 IAM/Bedrock 검사는
기존과 동일합니다. 일반 배포에서는 실험 설정을 자동 변경하지 않습니다.
실험을 끝내려면 해당 환경값을 false로 바꾸고 컨테이너를 재생성합니다.

로그인 패널은 웹 헤더 바로 아래로 이동했습니다. 메일 링크 로그인도 유지합니다.
검증: 격리 PostgreSQL 기반 비로그인 허용/기본 거절, 글로벌 비용·토큰 한도,
계정 저장 권한 보존 및 기존 AI 라우트 테스트 6개, 웹 빌드와 브라우저 검사.
실제 서버의 새 버전 실행은 사용자가 배포한 뒤 확인해야 합니다.
