# 실행 검증 결과

최종 검증: 2026-10-08, 클라우드 Linux 환경. 외부 API가 아닌 로컬 프로덕션 빌드 대상입니다.

| 실행 항목 | 결과 |
| --- | --- |
| `npm ci --cache /workspace/.npm-cache --no-audit --no-fund` | lockfile 설치 성공 |
| `npm run typecheck` | 통과 |
| `npm test` | 2개 파일, 64개 테스트 통과 |
| `npm run build` | 성공: 홈/404 정적 페이지, 조건 추출 서버 API |
| `npm run test:e2e` | 26개 통과: 데스크톱 13개 + 모바일 에뮬레이션 13개 |
| 부모님 소개 자료 PDF | Chromium PDF 생성 성공, 한글 텍스트 추출 확인 |
| 화면 확인 | 홈 데스크톱·일정 모바일 캡처 확인 |

최종 실행에서 실패·스킵 없이 완료했습니다. 개발 중 실패했던 초기 포커스, Next.js 알림 요소와 오류 메시지 선택 충돌, 오래된 빌드 서버 재사용, 테스트 간 요청 제한 상태 공유를 해결한 뒤 최종 결과를 확인했습니다. 요청 제한을 끄지 않고 별도 클라이언트를 사용하며 동일 클라이언트의 11번째 요청 차단도 검증합니다.

Node 24.19.0, npm 11.9.0, 시스템 Chromium 151.0.7922.173을 사용했습니다. Playwright 전용 Chromium 다운로드는 당시 네트워크 정책에서 403으로 차단되어 기존 시스템 브라우저를 사용했습니다. TLS·서명·체크섬 검증을 해제하지 않았습니다.

실제 OpenAI 요청은 수행하지 않았습니다. 실제 어댑터 테스트는 모의 응답으로 JSON 형식, ID, 원문에 없는 수치, 오류, 타임아웃을 검증합니다. 키가 없는 조건 추출 서버의 규칙 응답은 실제 브라우저 요청으로 검증했습니다.

실제 여행 데이터 연동, 외부 배포, 실제 iOS/Android 기기, 스크린리더 실기 검사, 물리 프린터, 새 클라우드 환경 복원은 미검증입니다. 고정 일정은 보존하지만 주변 자동 재배치는 지원하지 않습니다. 세부 한계와 실행 절차는 [README](../README.md)를 확인하세요.
