# 여행 시간 직접 선택 · 출발지 검색 개선

- 오전/오후 고정 선택을 시작 시간과 종료 시간 입력으로 변경했습니다. 매일 같은 시간 범위를 적용하며 같은 날 안에서 최소 30분을 선택합니다.
- 선택한 시간에 맞춰 방문 장소 수, 이동·휴식·식사 시간을 배치합니다. 짧은 여행은 관광지 한 곳도 지원하며 생성·저장·공유에 시간 범위를 보존합니다.
- 실제 도로 시간 재계산 시에도 방문 순서와 선택한 시간 범위를 지킵니다. 식사가 없는 짧은 일정에 기본 두 끼 비용을 더하지 않습니다.
- 판교고 → 판교고등학교, 분당중 → 분당중학교, 대치초 → 대치초등학교처럼 학교 줄임말을 일반 규칙으로 확장합니다. 특정 학교만 등록한 방식이 아닙니다.
- 판교역로235, 불정로77번길3 같은 주소의 띄어쓰기를 정리하고 도로명 검색을 우선합니다.
- 출발지 옆 주소 검색 버튼과 결과·실패 안내를 추가했습니다. 동명 장소는 후보를 선택합니다. 검색 범위는 지도 공급자에 등록된 국내 장소이며 모든 비공식 별칭을 보장하지 않습니다.
