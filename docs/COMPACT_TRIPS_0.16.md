구성합니다. 기존 긴 시설 표·미확인 나열·사용자 조사 입력폼을 기본 화면에서
제거하고 일정 수정/도로 조회/대체 추천은 접힌 메뉴로 이동했습니다.
운영시간·전화·입장료는 실제 값이 있을 때만 방문 정보에 표시합니다.

좌표를 평균한 대략적인 중심이며 첫날 후보 거리·방문 시작 순서와 AI 요청에
반영됩니다. 정밀 주소 지오코딩이나 출발지부터의 실제 교통시간을 뜻하지 않습니다.
인원은 1~20명이며 AI 요청과 저장된 코스의 인원·택시 대수에 반영합니다.
택시는 4인승 기준으로 올림 계산합니다. 실제 차량 예약이나 확정 요금은 아닙니다.

contact:website 37건을 확인했습니다(필드별 건수이며 서로 중복될 수 있음).
이전에 장소 변환 중 버려지던 주소·운영시간·홈페이지를 보존합니다.

추가 조회합니다. 8초 제한, 서버 캐시, 실패 시 기존 정보 유지로 동작합니다.
