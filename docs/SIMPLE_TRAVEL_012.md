# 여행잇 0.12.0 개선 및 검증 · 2026-11-03

## 수정한 다섯 항목

1. 추천과 대체 후보 조회·적용에 같은 예보 유효성 검사를 사용합니다. 날짜 불일치/2시간 만료는 재조회 또는 수동 선택으로 안내하고 일정 점검에도 표시합니다.
2. OSRM 도로 행렬로 방문 순서를 개선하고 전체 경로의 구간 거리·시간으로 일정과 입력 가정 기반 비용을 재계산합니다. 고정 출발/도착/복귀·다른 날짜를 유지하며 미리보기에서 명시적으로 적용합니다. 되돌리기는 이전 일정과 비용 계획을 복원합니다.
3. 비·한파·결빙·강풍 등 복합 위험을 함께 표시합니다. 영하 강수의 위험을 비 한 가지로 숨기지 않습니다.
4. Android 취소는 요청 ID 소유권을 확인해 실제 HTTPS 연결을 해제합니다. 취소 직후 재시도가 가능하며 이전 작업의 종료가 새 작업을 지우지 않습니다.
5. 지도 타일 오류·지연에 재시도를 제공하고 정상 표시되면 오류를 해제합니다. 도로 조회 실패를 직선 도로로 표시하지 않습니다.

## 추가한 사용 기능

- 하루 전체 지도, 번호가 붙은 방문 장소, 순서·시간·비용 비교.
- 날씨 확인과 실내 대안 비교 후 적용, 한 번에 되돌리기.
- 최근 확인된 주차장·승하차·화장실·엘리베이터 조건 필터.
- 출처/날짜가 있는 시설·영업시간·주간/특정일 휴무·예약 필요 기록과 출발 전 점검. 사용자 예약 확인은 예약 대행이 아닙니다.
- 기본 동작은 버튼으로 제공하고 상세 조건·한 구간 조회는 펼침 메뉴에 배치합니다.
- 다일 코스를 합칠 때 생성되는 임시 일정에도 해당 날짜의 날씨를 반영해 정상 코스가 잘못 차단되는 문제를 수정했습니다.

## 검증

- Vitest 25개 파일, 188개 테스트 통과.
- 데스크톱/모바일 도로·날씨·접근성·계정 화면 총 12개 시나리오 통과. 첫 실행에서 다일 날씨 2개가 실패해 원인을 수정했고 해당 2개와 새 코스 2개를 재실행했습니다.
- 웹 production 빌드, Android 빌드 및 APK v2/v3 서명 통과. 앱 ID와 기존 서명키 유지, versionCode 13.
- 최종 APK 웹 자산으로 오프라인 전국 검색, 자가용/택시, 도로 하루 코스 적용, 예보, 로컬 보관/복원/내보내기, AI 대체 브리지 계약을 합성 응답으로 검사했습니다.
- 실제 Java PublicTravel 코드를 Android/JSON 경계 스텁·가짜 HTTPS 연결로 실행해 취소·즉시 재시도·늦은 응답 억제를 확인했습니다.

실제 공급자·물리 Android·실제 AI 응답 검증은 위 검사와 다릅니다. 현재 개발 환경의 외부 공급자 연결 제한으로 실연결 성공은 확인하지 못했습니다. 시설/영업시간 자동 확보, 실제 택시 견적/호출·예약 접수도 제공 범위가 아닙니다. 자세한 운영 조건은 [LIVE_TRAVEL.md](LIVE_TRAVEL.md)를 확인하세요.
