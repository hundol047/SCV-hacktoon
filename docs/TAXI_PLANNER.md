# 택시 플래너 보완 (2026-10-17)

실제 장소를 조회한 뒤 ‘차 없는 대학생 · 택시 절약 여행’을 열어 사용합니다. 지도 핀 선택 대신 장소 목록을 사용합니다. 검색과 더 보기로 후보 전체에 접근할 수 있습니다.

- 출발지 고정, 마지막 도착지 고정 또는 출발지 복귀, 여행일 선택, 차량당 탑승 정원을 지원합니다.
- 기본요금을 한 번만 더하던 오류를 수정했습니다. 각 구간에서 새 택시에 탑승하는 가정으로 `(구간 수 × 기본요금 + 직선거리 × km당 요금) × 차량 수`를 계산합니다. 복귀 구간도 포함합니다. 실제 택시 요율표·도로 거리·시간요금에 따른 견적은 아닙니다.
- 입력 변경 시 저장된 계산을 해제합니다. 잘못된 숫자는 화면 오류로 처리하며 예외로 화면을 중단하지 않습니다. 예전 계산 결과에는 재계산 안내를 표시합니다.
- 시작·도착 조건, 여행일 범위, 요금 합계, 차량 수를 저장 스키마에서도 확인합니다.
- 하루 안에 전체 방문과 복귀를 배치할 수 없으면 부분 일정을 저장하지 않습니다. 고정 일정이나 가족 의견이 있으면 자동으로 덮어쓰지 않고 기존 일정과 조정 안내를 반환합니다. 다른 날짜의 기존 일정은 유지합니다.
- 실제 경로가 없는 이동의 20분과 방문 45분은 편집용 배정입니다. 시설·계단·보행·식사 적합성은 기존 검증기로 계속 점검합니다.

여러 날짜를 한 번에 택시 순서로 최적화하거나 실제 도로별 최저요금을 계산하는 기능, 지도에서 핀 찍기, 택시 예약은 아직 지원하지 않습니다. 현재 택시 계획은 선택한 하루에 적용하며 나머지 날짜는 기존 일반 일정 생성 또는 기존 일정을 사용합니다.

검증: 타입 검사·프로덕션 빌드, 전체 단위 155개, Chromium 데스크톱·모바일 구성에서 택시 플래너와 기존 실제 여행 흐름 6개 통과. 브라우저 검사는 장소 API 응답을 테스트 자료로 대체해 UI·저장 흐름을 검증했으며 외부 공급자 연결·실제 택시 견적 검증이 아닙니다. 첫 전체 검사에서 빌드와 동시에 실행한 전국 자료 검사가 5초 제한을 넘겼지만 빌드 종료 후 전체 재실행은 통과했습니다.
