## 적용과 남은 운영 검증

최신 DB는 001 → 003 → 005~012 순서로 적용하며 스키마 12를 요구합니다. 이미 적용한 마이그레이션은 반복하지 않습니다. 008이 과거 정리 작업을 대체합니다. 실제 PostgreSQL 17에서 pg_cron 실행과 public·auth 암호화 백업/복원을 검증했습니다. 최신 0.4 감사의 수정 범위는 [출시 준비 기록](RELEASE_READINESS.md), 상세 절차는 [배포 문서](DEPLOYMENT.md)를 확인하세요.

현재 운영 계정·Supabase/AI/경로 인증값이 없어 공개 배포, 실제 AI·경로 연결, 운영 DB 복원·정기 삭제·알림 수신 검증은 완료하지 못했습니다. 실제 모바일 기기·스크린리더도 별도 검증 대상입니다. [배포 절차](DEPLOYMENT.md)에 필요한 설정과 검증 순서를 기록했습니다.

최신 실제 여행은 최대 30일·10도시, 도시당 반경 1~50km·후보 최대 200개입니다. 이메일 계정·Turnstile·시설 독립 검토·시간대/통화와 운영 지표를 추가했습니다. 세계 전체 장소의 시설을 검증하거나 모든 여행 동선을 지원한다고 주장하지 않습니다.
