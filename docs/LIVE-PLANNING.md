# 숙소·비용·공유 계획 운영

## 활성화
Supabase SQL Editor에서 `supabase/migrations/014_live_plans.sql`을 한 번 실행합니다. 동행자 장소 의견은 기존 013도 필요합니다. 기존 서버 환경변수는 유지합니다. 새 예약 API 키는 필요하지 않습니다.

## 제공 범위
- 국내 차량 일정 최대 5일. 숙소 체크인/체크아웃, 숙소→다음 날 첫 장소, 마지막 관광지→숙소를 실제 도로 조회로 배치합니다. 시간 내 배치할 수 없으면 기존 일정을 보존합니다.
- 숙소 가격은 사용자가 입력한 **해당 1박 전체 객실 합계**를 우선하고, 없으면 객실 수×숙박 예상 단가입니다. 예약 가능 여부와 실시간 최저가 API는 없습니다.
- 날짜별 시간은 기본 시간보다 우선하며 마지막 날 집 도착 제한은 별도로 적용됩니다.
- 교통 예산은 도로 거리 기반 가정입니다. 택시 구간당 4,800원+km당 1,250원, 자가용 km당 250원. 실제 지역 운임, 할증, 통행료가 아니며 사용자의 일별 교통비 입력이 우선합니다.
- 비용 절약은 유료 방문 1개 축소, 여유안은 방문 1개 축소와 휴식 확대, 이동안은 가까운 순서 재배열 후 실제 도로 재계산입니다. 전역 최적 코스 또는 반드시 더 저렴한 결과를 보장하지 않으며 비교 후 적용합니다.

## 공유·투표
- 작성 브라우저의 서명된 익명 세션이 소유권을 가집니다. 링크는 256비트 임의 토큰으로 DB에는 해시만 보관합니다.
- 초대 링크 보유자는 공개 일정(출발지·숙소·예상 비용 포함)을 읽고 브라우저별 1표를 행사합니다. 실명 인증 투표가 아닙니다. 작성자 세션을 지우면 해당 링크 편집권을 잃으므로 새 공유를 생성해야 합니다.
- 15초 간격 조회. 작성자의 비용 수정은 공유 원본에 전달되며 기존 미확정 제안은 취소됩니다. 숙소/코스 변경 미리보기는 제안→인원 과반 찬성→작성자 확정 순서입니다.
- DB는 revision 비교로 오래된 버전 덮어쓰기를 거부합니다. 링크 만료 30일, 소유자당 20개, 전체 5,000개. 새 링크 생성 시 만료 자료를 삭제합니다.
- 기존 압축 사본 링크도 계속 열립니다. 사본 링크는 갱신되지 않습니다.

## 할인 데이터 관리
`src/data/travel-benefits.ts`에 공식 링크·대상·지역·시설·사용 기간·재검토 기한을 함께 등록합니다. 금액 계산이 가능한 **1인 입장료 비율**만 `discountRate`에 기록합니다. 차량당 레일바이크, 유료 패스, 정액 상품은 1인 입장료로 환산하지 않습니다. 신규 정책은 공식 제공처 확인 후 추가하며 단순 URL 응답 성공을 할인 조건 검증으로 간주하지 않습니다.

`selectBenefits`는 사용일과 현재 날짜, 재검토 기한이 지난 혜택을 제외합니다. 사용자가 별도로 확인한 할인은 해당 방문의 전체 할인액·조건·공식 링크·만료일로 저장합니다. 동일 방문의 할인은 가장 큰 한 개만 적용하고 입장료를 초과하지 않습니다. 현재 전국 지역별 공식 목록은 제공하지만 모든 지역의 개별 쿠폰을 자동 수집하지 않습니다.
