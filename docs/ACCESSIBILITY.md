# 실기기와 스크린리더 점검

2026-10-08 · 현재 실기기·VoiceOver·TalkBack 검사는 **미실행**입니다. Linux의 Chromium·모바일 Chromium·Firefox·WebKit 및 axe 검사는 별도 자동 검증이며 실제 기기 사용성을 증명하지 않습니다.

## 자동 기기 검사

공개 검사 주소와 BrowserStack 계정을 비밀 설정에 넣고 `npm run test:devices`를 실행합니다. 실제 iPhone/Android 브라우저에서 시연, 큰 글씨 부모님 화면, 의견 반영 알림, 가로 넘침을 확인합니다. 실패 시 세션을 정리하고 실패를 반환합니다. 계정 없이는 실행 성공으로 표시하지 않습니다.

## 사람이 확인할 항목

| 환경 | 확인할 흐름 | 통과 기준 |
| --- | --- | --- |
| iPhone Safari + VoiceOver | 홈 → 여행 입력 → 점검 → 부모님 화면 → 의견 → 되돌리기 | 읽기 순서·컨트롤 이름·오류·상태 알림이 이해 가능하고 화면 밖 요소에 초점이 갇히지 않음 |
| Android Chrome + TalkBack | 같은 흐름과 가족 링크 읽기 | 버튼·필드·시간표·미확인 근거·의견 결과를 탐색하고 조작 가능 |
| 키보드 | 모든 단계·대화상자·검토/운영 화면 | Tab 순서·가시적 초점·Enter/Space 조작·대화상자 닫기/초점 복원 정상 |
| 확대·큰 글씨 | 브라우저 200%/400%, OS 글자 확대·가로/세로 전환 | 내용·버튼이 잘리지 않고 꼭 필요한 시간표 외에 가로 이동 불필요 |
| 이동일·다도시 | 날짜 변경선 여행, 재방문, 하루 전체 이동 | 현지 날짜·출발/도착·출처와 미확인 상태를 부모님이 이해 가능 |
| 인쇄 | 실제 프린터와 PDF | 일정·의견·미확인 근거가 페이지 경계에서 잘리지 않고 글자 읽기 가능 |

각 결과에 날짜, 기기/OS/브라우저/보조기술 버전, 검사자, 수행 흐름, 실패 증상과 재현 방법을 기록합니다. 사용자 개인정보·인증키는 기록하지 않습니다. 실패 항목을 수정하고 해당 흐름을 다시 실행한 뒤 통과로 바꿉니다.

실제 이메일 코드 수신·Turnstile 챌린지·공유 링크는 운영 전용 합성 계정/여행으로 확인합니다. 테스트가 끝나면 생성한 여행과 공유 권한을 정리합니다.
