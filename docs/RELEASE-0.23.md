# 여행잇 0.23.0

여행 취향을 단일 선택 목록에서 다중 선택 버튼으로 변경했습니다. 선택 상태를 색상과 aria-pressed로 표시하고, 다시 누르면 해제합니다. ‘골고루’는 개별 취향을 초기화합니다. 기존 취향 배열을 보존하고, 선택한 전체 배열을 AI 요청과 여행 저장 데이터에 전달합니다.

일정의 해당 장소 이름 아래에 등록된 할인 요약과 간단한 이용 조건, 기간, 공식 제공처 링크를 표시합니다. 같은 지역에 있다는 이유만으로 특정 시설의 혜택을 다른 장소에 붙이지 않도록 시설명과 등록 별칭이 일치할 때만 표시합니다. 기존 날짜·종료·확인일 필터를 재사용하고 할인액은 자동 차감하지 않습니다. 공유 일정에도 동일하게 표시합니다.

혜택 정보 자체는 0.22의 2026-11-06 공식 출처 확인 자료를 유지했습니다. 이번 변경은 화면과 매칭 동작 변경이며 새로운 혜택 확인으로 갱신 날짜를 연장하지 않습니다.
