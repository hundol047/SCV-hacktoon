# 여행잇 0.18 — 지도 핀, 빠른 일정 생성, 출발지 주변 교통시설

## 지도
모든 일정/공유 일정의 장소 링크는 유효한 좌표가 있으면 카카오맵 위치 핀을 엽니다. 장소명+시도명 검색 결과에 의존하지 않으므로 네이버에 업체명/자연명소가 등록되지 않아 발생하던 검색 실패를 피합니다. 좌표가 없는 경우에만 주소(없으면 이름) 검색으로 대체합니다. 실제 폐업/이전 여부를 검증하거나 외부 지도 업체 등록을 수정한 것은 아닙니다. 기존 장소 좌표가 잘못됐으면 해당 위치도 잘못 표시될 수 있습니다.

## 속도
간편 입력의 1~5일 일정은 `allDays:true`로 한 번의 Bedrock Converse 요청에서 생성합니다. 3일 기준 모델 호출 3회→1회이며 요청/예산 예약도 1회입니다. 공통 장소 사실/조건은 프롬프트에 한 번만 담고 날짜별 후보/날씨를 따로 전달합니다. 각 날짜 2~3개 관광지를 기존 지역/날씨/시설/중복 검증으로 다시 확인합니다. 누락 날짜·다른 날짜와 중복·허용 후보 밖 ID는 거부하며 기존 일정을 유지합니다. 단일 날짜 편집 API도 유지합니다.

지역 후보 조회와 출발지 검색을 병렬로 실행하고 같은 출발지 검색은 재사용합니다. 선택된 장소의 추가 운영시간/전화 조회는 일정 표시 후 화면에서 보완하여 생성 완료를 막지 않습니다. 기존 저장 데이터 자체를 비동기 덮어쓰지 않습니다. GPT 모델, IAM 인증, 비용 단가/일일 한도는 변경하지 않았습니다. 실제 모델 응답시간 자체의 감소는 아직 측정하지 않았습니다.

## 출발지 교통시설
출발지를 입력하고 다음 입력칸으로 이동하면 주소를 확인합니다. 주소가 여러 개면 선택 후 진행합니다. 확인한 좌표에서 25km 안의 OSM 버스터미널과 일반 철도역을 조회해 종류별 가까운 3곳, 최대 6곳을 직선거리와 함께 보여줍니다. 지하철/경전철/모노레일로 분류된 역은 제외합니다. 조회는 일정 생성과 독립적이며 실패 시 재조회/지도 검색을 제공합니다. 지도 위치 및 출발지→역/터미널 길찾기를 제공합니다. 노선/좌석/승차권 예약 가능 여부는 예약 사이트에서 확인해야 합니다.

Android에도 지도 핀/일괄 AI 요청/주변 교통시설 조회를 반영했습니다. 네이티브 서버 요청은 최대 4개 동시 허용하며 모델 60초 제한과 클라이언트 타임아웃을 맞췄습니다. 주위 시설 조회는 캐시/요청 재사용으로 화면 이동 때 중복 요청을 줄였습니다.

추가로 부산 등 시도 전체를 입력해 시군구 검색어가 비어 있는 경우에도 국문 TourAPI 공식 관광지/문화시설/음식점 후보가 보완되도록 수정했습니다. 공식 후보 추가는 웹 서버 경로입니다.

검증은 단위 테스트와 모의 공급자/AI 응답을 사용하는 PC·모바일 브라우저, APK 웹 자산 테스트로 수행합니다. 실제 EC2 Bedrock 지연, 외부 지도 서비스 핀 표시, 주변 시설 공급자의 현장 데이터, Android 실기기는 별도 검증이 필요합니다.
