# 1~7번 출시 준비 결과

2026-10-08 · Bopok 0.3.0. 요청한 7개 항목의 코드·마이그레이션·자동 검사·배포 절차를 구현했습니다. **운영 계정과 인증값이 없는 상태이므로 실제 공개 서비스 개통은 완료되지 않았습니다.** 계정/키가 필요한 검증을 로컬 성공으로 대체하지 않습니다.

| 항목 | 해결한 내용 | 실제 운영에 남은 조건 |
| --- | --- | --- |
| 1. 구형 DB 준비 판정 | 스키마/함수 계약 11, 기능·서명 키 검사. 001만 있으면 미준비, health 503 | 운영 Supabase에 마이그레이션 적용 |

## 확인한 증거

- 타입·프로덕션 빌드 통과, 단위/SQL **111개**, 브라우저 **88개** 통과.
- 실제 PostgreSQL 17에서 스키마 11과 예약 정리 작업 실행을 확인했습니다. 암호화 백업을 새 DB에 복원해 데이터/RLS를 확인했고 변조·잘못된 키·비어 있지 않은 대상은 거부했습니다.
- 격리 앱에서 요청 100회/동시 10개, p95 95ms를 기록했습니다. 이 결과는 상태/규칙 API의 소규모 측정이며 운영 트래픽 보증은 아닙니다.
- 코드의 계정·봇·시설 검토는 모의 공급자/격리 SQL로 검증했습니다. 실제 메일·유료 AI·경로 호출·기기 검증과 구분합니다.

세계 도시 검색은 전체 세계 데이터 확보를 뜻하지 않습니다. 출처가 없는 시설·메뉴·계단·요금은 계속 미확인입니다. Overpass의 실제 호출은 이번 검사에서 504를 반환했고 환율 도메인은 현재 환경에서 차단되었습니다. 외부 공급자의 성공을 보장하지 않습니다.

## 운영 개통 순서

1. [배포 절차](DEPLOYMENT.md)에 따라 Supabase 스키마 11·Auth·검토자·Turnstile·모델/경로 키를 연결합니다.
2. 알림 수신처와 백업 비밀을 설정하고 격리 복원을 성공시킨 뒤 기록합니다. 최초 백업 게이트가 통과해야 운영 준비 검사가 성공합니다.
3. Vercel 미리보기를 배포해 실제 로그인·세계 도시·경로·최소 AI 호출·권한·운영 점검을 확인하고 readiness 검사 후 운영 배포합니다.
4. 실제 기기/스크린리더와 사용 지역의 독립 시설 확인을 마칩니다. 클라우드 환경 설정 초안은 검토·저장·게시해야 적용됩니다.

실행 명령과 관측 범위는 [검증 기록](VALIDATION.md)에 남겼습니다. 운영 프로젝트·비밀값을 임의로 만들거나 공개하지 않았으며, 비용이 발생하는 계정 등록은 수행하지 않았습니다.
