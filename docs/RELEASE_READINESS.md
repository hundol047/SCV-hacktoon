# 여행잇 현재 상태 · 2026-11-03

0.10.1에서 AI 키 없이 가능한 행사 백업/즐겨찾기 복원·목록 확장, 차량 코스 날짜/지역/날씨 검사, 외부 지도 길찾기, 실내외 확인 기록, APK의 미연결 서버 기능 안내를 개선했습니다. 외부 지도 열기는 실제 도로 정보를 앱으로 가져오거나 요금을 계산하는 기능이 아닙니다.

## 이번 버전 검증

단위 테스트 178개, 데스크톱/모바일 브라우저 E2E 14개, TypeScript와 웹 프로덕션 빌드 통과. Android APK 서명 v2/v3와 versionCode 11 확인. APK용 웹 자산의 브라우저 검사에서 국내 검색·차량 코스·백업 흐름과 미연결 서버 버튼 제거·지도 링크·실내 기록 저장을 확인했습니다. 실제 Android 기기와 외부 지도 앱 실행, 실시간 공급자 호출을 검증한 것은 아닙니다.

## 사용자 도움이 필요한 사항

| 필요한 작업 | 필요한 정보 또는 조치 |
| --- | --- |
| 안드로이드 실기기 검증 | 기존 앱을 삭제하지 않고 업데이트한 뒤 일정 유지·JSON 백업/복원·지도 열기·뒤로가기를 확인. 오류 시 기종·Android 버전·발생 화면 제공 |
| 공개 서버·계정·동기화 | 배포 플랫폼 계정/프로젝트와 도메인, 데이터베이스 프로젝트 연결. 저장소의 DEPLOYMENT 절차에 따라 환경 변수 설정 |
| 공식 축제·관광지 자동 갱신 | 한국관광공사 TourAPI 사용 승인 키를 환경 설정의 BOPok_TOURAPI_KEY에 등록 |
| 앱 내 도로 경로·대중교통 | openrouteservice BOPok_ROUTE_KEY, 필요 시 Google BOPok_GOOGLE_MAPS_KEY 및 사용량/비용 설정. 택시 실요금/호출은 별도 사업자 연동 필요 |
| 실시간 날씨 | 아직 구현·검증되지 않음. 공개 서비스의 상업 이용 조건과 운영 범위에 맞는 예보 공급자 선정·연결 필요. 현재는 수동 날씨 시나리오만 제공 |
| 해외 장소 조회 | 기존 서버 경유 지도 검색의 공개 서버와 Nominatim/Overpass 네트워크 연결 필요. 전체 세계 장소를 수집했다는 의미가 아님 |
| 시설 정보 최신화 | 실제 장소/공식 출처 확인 기록과 운영 담당자 검토. 자동으로 접근성·영업 여부를 확정할 수 없음 |

AI 키 등록과 실제 AI 호출 검증은 사용자 요청에 따라 보류합니다. 비밀키는 채팅/저장소 대신 환경 설정에 넣습니다. 현재 클라우드 런타임에는 외부 공급자 자격 증명이 설정되지 않았으며 지도/날씨 공급자 도메인은 허용 목록에 없습니다. 아래 기록은 **이전 버전 검증 이력**이며 이번 실행 결과와 구분합니다.

## 실행한 검증

- 타입 검사와 프로덕션 빌드 통과. 단위/SQL **132개**, 브라우저 **112개 고유 항목** 통과. 전체 실행과 검사 fixture 수정 후 재실행의 구분은 [검증 기록](VALIDATION.md)에 있습니다.
- 0.4.0에서 실제 PostgreSQL 17 + pg_cron의 스키마 **12**, 예약 정리 실행, **합성 Auth 계정과 여행의 암호화 백업/복원**을 확인했습니다. 별도 서버의 누락된 역할도 재생성했습니다. 0.4.1은 DB/백업 변경이 없어 해당 검증을 유지합니다. 운영 Supabase Auth 서버 복원 결과는 아닙니다.
- 0.4.0 격리 DB/앱 부하 검사: 동시 사용자 **20명·240요청**, p95 **222ms**, 검사 여행 삭제 확인. 유료 호출 0회입니다.
- 최신 비루트 Docker runtime에서 홈/규칙/liveness 성공과 미구성 readiness 503 확인.
- 운영 도메인 전환 실패 시 복구, 연결 실패/키 변경·기록 만료, 앱 다운 외부 알림·중복 억제는 모의 endpoint로 검증했습니다. 실제 배포/알림 수신 성공으로 해석하지 않습니다.

## 현재 외부 조건

Vercel·Supabase·유료 경로/AI·BrowserStack 자격 증명이 제공되지 않았습니다. 계정 없이 가능한 Vercel CLI 임시 배포도 시도했으나 “Temporary deployments aren't available for this attempt”와 로그인 필요 오류로 종료했습니다. 공개 URL이 생성되지 않았습니다.

Frankfurter 실환율 연결은 성공했지만 Overpass는 이번 검사에서 504였습니다. 세계 도시 검색이 세계 전체 장소의 완전한 데이터·시설 검증을 뜻하지 않습니다. 출처가 없거나 오래된 사실은 미확인입니다.

운영 연결 순서는 [배포 절차](DEPLOYMENT.md), 실제 수행 범위는 [검증 기록](VALIDATION.md), 실기기 절차는 [접근성 점검표](ACCESSIBILITY.md)에 있습니다. 클라우드 설정은 초안으로 저장하며 환경 설정에서 검토·저장·게시해야 적용됩니다. 기능 브랜치 푸시만으로 기본 브랜치의 예약 작업이나 운영 서비스가 활성화되지 않습니다.
