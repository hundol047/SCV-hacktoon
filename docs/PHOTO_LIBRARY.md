# 여행잇 0.13.0 사진 화면

첫 화면의 SVG 일러스트를 실제 미국 아치스 국립공원 사진으로 교체했습니다. Joshua D. Warner의 2014년 촬영 사진이며 CC BY 4.0입니다. 원본은 scikit-image/skimage-tutorials의 커밋 26e2d4d27113a86b9dd99dc7e559ab25aa782436, images/pano/JDW_0302.jpg입니다. 원본 바이트를 변경하지 않고 CSS로 표시 영역을 조정합니다. 화면에 촬영자·장소·원본·라이선스 링크를 표시하며 public/images/PHOTO-LICENSE.txt를 웹과 APK에 포함합니다.

여행 보관함의 기본 화면은 ‘사진 올리기’와 사진 카드입니다. JPG/PNG/WebP를 여러 장 선택할 수 있고, 전체 40장·원본 한 장 10MB까지 허용합니다. 긴 변 1600px 이하 JPEG로 변환해 IndexedDB에 저장합니다. 원본을 대체하는 백업 기능은 아닙니다. 사진의 파일 메타데이터는 canvas 변환 결과에 복사하지 않습니다. 실제 사진 내용과 원래 파일명은 보관됩니다.

사진은 현재 기기의 브라우저 저장소에만 저장하며 서버/S3/AI로 업로드하지 않습니다. 브라우저나 접속 주소(IP·도메인·포트)를 바꾸면 공유되지 않습니다. 개별 삭제와 ‘내 여행 데이터 삭제’를 지원합니다. 사진은 기존 JSON 일정 백업에 포함되지 않습니다. 일정 백업은 접힌 ‘일정 백업·복원’ 메뉴에서 사용합니다.

Android는 이미지 MIME 유형과 다중 선택을 지원하도록 문서 선택기를 수정했습니다. Blob 이미지용 CSP와 내장 JPEG MIME을 반영했습니다. 외부 저장소 전체 읽기 권한은 추가하지 않습니다.

배포 ZIP은 `python3 scripts/package-powershell.py`로 생성합니다. Ubuntu 기본 Docker 빌더를 지원하도록 배포용 Dockerfile에서 개발 환경 전용 proxy CA mount를 제거합니다. ZIP에는 환경 키·서명키·빌드 캐시를 넣지 않습니다.

검증(2026-11-03): 단위 188개, 데스크톱/모바일 사진·기존 일정 백업/복원·데이터 무결성 화면 16개 통과. 보관함에서 모든 여행 사진을 볼 수 있도록 표시 범위를 정리한 후 사진 시나리오 2개를 재실행해 통과했습니다. 최종 웹/Android 빌드·APK v2/v3 서명, APK 웹 자산의 실제 JPEG/Blob 사진 표시·저장·복원·삭제와 기존 모바일 주요 흐름도 통과했습니다. Windows/EC2 배포와 실제 Android 문서 선택기는 이 환경에서 직접 실행하지 않았습니다.
