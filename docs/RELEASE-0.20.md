# 여행잇 0.20.0

홈의 ‘예시 체험’ 버튼을 제거하고 실제 앱 화면을 촬영한 약 23초 사용 안내 영상을 추가했습니다. 지역·시간대 선택, 일정 확인, 공유 링크 생성과 캘린더 저장 버튼을 안내합니다. 영상은 예시 응답으로 촬영했으므로 실제 AI 응답 시간이나 실시간 교통 정보를 나타내지 않습니다.

영상은 화면에 들어오면 무음으로 재생되며 기본 재생 컨트롤과 한국어 자막을 제공합니다. 동작 줄이기 설정에서는 직접 재생합니다. 영상과 포스터·자막은 서버 및 Android 앱에 함께 포함됩니다. Android 자산 응답은 MP4 MIME 및 범위 요청을 지원합니다.

홈 관광지 사진은 한국 날짜별 시작 사진에서 8초마다 자동 전환합니다. 이전·다음과 일시정지 버튼을 제공하고, 동작 줄이기 설정을 존중합니다. 외부 사진 로딩 실패 시 다음 사진으로 넘어가며 모두 실패하면 재시도할 수 있습니다. 현재 온라인 사진 풀은 3장입니다. 기존 출처·라이선스 정보는 유지합니다.
