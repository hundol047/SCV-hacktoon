# MY-AI-LAB → 여행잇 강원 화면 이식

참조: https://github.com/hundol047/MY-AI-LAB/tree/7f24645/travel-planner
대상: SCV-hacktoon, 기존 feat/bopok-mvp의 24f6681 기반.

MY-AI-LAB의 청록색 테마·둥근 카드·사진 헤더·접이식 수동 입력·5개 강원 권역·일정과 지도 배치를 기존 React 컴포넌트에 적용했다. 원본의 정적 HTML/app.js를 덮어쓰는 대신 기존 여행잇 API와 상태 관리를 연결한다.

- 강릉·동해 / 속초·양양 / 춘천·철원 / 평창·정선 / 원주 권역. 세부 18개 시·군 모두 선택 가능.
- 관광지 검색은 KR-42로 한정. 출발지는 전국 주소·현재 위치를 계속 지원.
- 기존 Bedrock 서버, 모델·환경변수, AI 프롬프트, 후보 검증, 과금 제한과 API 경로는 변경하지 않는다. 원본의 OpenAI/내장 가이드는 이식하지 않는다.
- 결과는 일정 / 숙소 / 예산·할인 / 여행 도우미로 분리. 숨긴 패널의 입력 상태를 유지한다.
- 공유·캘린더·접근성·숙소 사진/예약 비교·일정 수정 기능을 유지한다.
- 강원 사진은 원본 저장소의 한국관광공사 장소-사진 대응을 사용한다. 원본 링크를 표시하고, 실패 시 재시도와 텍스트를 제공한다. 실시간 사진 제공 여부와 실제 AI 호출은 운영 환경의 공급자 연결이 필요하다.
- 기존 사용 안내 영상은 접이식 안내에 남겼다. 이번 화면의 새 녹화본은 아니다.

## 실행

```powershell
git clone -b feat/gangwon-lab-ui https://github.com/hundol047/SCV-hacktoon.git yeohaengit-gangwon
cd yeohaengit-gangwon
npm ci
npm run dev
```

http://localhost:3000 에서 확인한다. 기존 서버의 AI 키를 새로 발급하거나 변경할 필요가 없다. 새 로컬 실행 환경의 AI 호출에는 기존 환경 설정이 필요하다. 키를 Git에 커밋하지 않는다.

## 검증

```sh
npm run typecheck
npm run build
npm run test -- tests/bedrock-routes.test.ts tests/bedrock-json.test.ts tests/anonymous-ai.test.ts tests/ai.test.ts
npx playwright test --config playwright.lab.config.ts
```

브라우저 테스트는 외부 API를 고정 응답으로 검증한다. 강원 조회 범위와 AI 요청 계약, 모바일 정렬·접근성, 숙소 이미지 실패 대체/더보기, 날짜별 지도 전환을 확인한다. 기존 전국 홈 화면 전용 테스트는 이번 강원 홈 구성과 다르다.

## 핵심 서비스 방향

부모님이나 이동이 불편한 동행자와 함께하는, 이동 부담이 적은 강원 여행을 중심으로 첫 화면·입력·결과를 구성한다. 연령만으로 신체 조건을 추정하지 않는다.

- 기본 선택: 여유로운 일정(comfort 우선순위 / slow 활동), 관광 후 20분 휴식. 사용자가 해제하거나 시간을 바꿀 수 있다.
- 연속 보행 한도와 필요한 시설은 동행자에 맞춰 직접 선택하며, 별도 메뉴를 열지 않아도 처음부터 보인다.
- 결과의 이동·휴식 요약은 요청한 계획 조건이다. 현장 시설 확인 완료나 무장애 경로 인증으로 표시하지 않는다.
- AI 모델·프롬프트·API는 유지하고 기존 요청의 조건 값에 선택 내용을 전달한다.

## 정부 반값여행 안내 연결 (2026-11-09 확인)

출처: 한국관광공사 https://korean.visitkorea.or.kr/dgtourcard/tour50.do 및 문화체육관광부 https://www.korea.kr/news/policyNewsView.do?newsId=148970744

강원 참여 지역 영월·화천·평창·횡성에만 지역별 안내를 표시한다. 정부 사업의 고성은 경남 고성이므로 강원 고성에 적용하지 않는다. 영월 6차 방문기간 11/7~11/22, 화천 2차 11/1~11/30. 평창·횡성의 현재 확인한 회차는 마감으로 표시한다. 지역 및 방문일 매칭과 공식 신청 안내 링크 연동이며, 잔여 예산 실시간 API나 자동 신청 기능은 아니다.

스냅샷 확인일을 표시하며 7일이 지난 접수 안내는 재확인 상태로 바꾼다. 기간 밖 방문과 마감은 구분한다. 사전 신청·승인, 실제 주민등록 거주지, 방문·결제 증빙을 확인해야 하므로 신청 자격 확정이나 환급액의 예산 자동 차감을 하지 않는다. 다음 회차가 공고되면 src/domain/half-price-travel.ts의 기간·상태·확인일을 공식 자료로 갱신해야 한다.

### 일정 기반 신청 초안

반값여행 안내가 표시된 선택 일정에서 사전신청 여행계획과 여행 후 정산 설명 초안을 만든다. 일정 날짜·방문 장소·시간·인원·설정 예산을 로컬에서 채우고, 내용을 편집·복사하거나 UTF-8 텍스트로 내려받는다. 일정이 바뀌면 새 내용으로 갱신한다. 대표자 성명·주민등록 거주지·실제 경비·승인번호는 빈칸이며 실제 영수증·사진을 생성하지 않는다. 여행 후 정산 초안에는 예정 장소를 방문 완료 사실로 넣지 않는다. 문서는 공식 양식 자동 작성/제출이 아닌 붙여넣기용 초안이며 작성 내용을 별도 서버로 전송하지 않는다.

### 실제 증빙 보관·자동 읽기

일정 ID와 사업 지역별로 원본 영수증·방문사진 및 읽기용 사본을 IndexedDB에 보관한다. 같은 원본의 중복 업로드를 막고, 삭제·원본 다운로드와 ‘내 여행 데이터 삭제’를 지원한다. 기본 저장은 이 브라우저에 한정되며, 공유 링크나 서버 계정으로 증빙을 전송하지 않는다. 브라우저 초기화 시 함께 삭제되므로 원본 백업이 필요하다.

사용자가 사진 전송에 동의하면 업로드 후 기존 Bedrock 모델/EC2 IAM 설정을 재사용하는 신규 /api/evidence-read에서 자동으로 읽는다. 기존 일정 AI 구현·프롬프트·모델 값은 그대로다. 서버는 출처·동의·사진 형식·크기를 검사하고 기존 AI 예산 제한을 적용한다. EXIF 등 메타데이터가 제거된 JPEG 사본만 AI로 보낸다. 읽기 실패 시 원본은 유지하고 수동 입력 및 재시도를 제공한다.

사진에서 식별한 결제처·날짜·금액은 미확인 초안이다. 사용자가 원본과 대조해 확인 저장한 자료만 정산 글과 지출 합계에 들어간다. 방문사진의 장소·날짜가 명확하지 않으면 빈칸이며 방문 사실·지원 자격·최종 환급을 인증하지 않는다. 아직 확인하지 않은 자료, 다른 일정/지역의 자료는 합계에서 제외한다. 증빙을 수정·삭제하면 문서도 갱신한다. 텍스트 초안과 원본 파일을 내려받아 공식 창구에 제출하는 방식이다.

검증 범위에는 실제 Bedrock 운영 이미지 호출이 포함되지 않는다. 운영 환경 모델의 이미지 입력 지원과 IAM 권한이 필요하며 연결 실패 시 수동 입력으로 계속 사용할 수 있다.
