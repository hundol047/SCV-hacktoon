# 0.4.1 추가 결함 수정

2026-10-08. 저장·가족 공유·실제 여행 자료를 다시 점검하고 다음 문제를 수정했습니다. DB 마이그레이션과 의존성 버전은 변경하지 않았습니다. 운영 계정이 필요한 작업의 상태는 [출시 준비 기록](RELEASE_READINESS.md)에 있습니다.

| 발견한 문제 | 수정한 동작 | 검사 |
| --- | --- | --- |
| 512 KB가 넘는 정상 내보내기 파일을 다시 가져오지 못함 | compact JSON 내보내기/가져오기에 동일한 8 MiB 제한. 실제 크기 초과 이유 표시 | 1 MB 이상의 이전 일정 포함 여행을 내보내고 같은 파일 재가져오기 |
| 보관함 항목 하나가 손상되면 다른 정상 여행도 사라진 것처럼 표시됨 | 개별 여행을 검증해 정상 항목 보존. 현재 여행 저장 성공 후 보관함 quota 실패도 별도 안내 | 손상 항목 사이의 정상 여행 유지·갱신, quota 실패 시 기존 보관함과 현재 저장 유지 |
| 지도 새로고침에서 이전 일정에만 쓰인 장소가 삭제됨 | 현재·모든 되돌리기 항목의 장소를 우선 보존. 원래 날짜와 사용자 확인 기록 유지. 기존 환율은 날짜를 유지해 사용 | 후보에서 빠진 장소로 되돌려도 이름·근거 유지 |
| 장소 좌표가 바뀌어도 예전 경로를 그대로 사용함 | 출발/도착 좌표가 바뀐 경로 제거 후 미확인·재조회. 후보 2,000개 한도에서는 현재/이전 일정 장소 우선 | 좌표 변경 시 기존 경로 제거·원본 자료 불변 |
| 가족 링크에서 대중교통이 택시로 표시되고 시각별 경로·이동일 누락 | 이동 수단 표시와 현지 출발 시각에 맞는 경로 사용. 이동일 시각·출처 표시, 독립 검토 서명 확인 | 가족 페이지의 대중교통 16분·이동일·axe 검사 |
| 여행 전환·로그아웃 뒤 늦은 서버 응답이 이전 여행/계정 UI를 복원함 | 요청 시 여행 ID 및 컴포넌트 생존 여부 확인. 계정 변경 시 공유 상태 초기화, 이전 응답 적용 차단 | 응답을 지연시킨 상태에서 다른 파일 열기/로그아웃. 제목·연결·비공개 링크 재등장 없음 |
| 경로 ID가 실제 출발·도착·수단·시각과 달라도 입력 허용 | 경로 식별 값 일치와 대중교통 출발 시각 필수 검증 | 다른 장소의 경로 사실로 연결한 입력 거부 |
| 미래의 환율·수집 시각이 최신 근거로 처리됨 | 미래/누락/만료 시각은 신선한 근거가 아님. 미래 환율은 환산 차단, 미래 경로는 재조회 | 미래 FX 환산 null, 미래 장소 자료 미확인 |
| 경로 자료가 없을 때 잘못된 출발지를 놓치거나 도착 후 이동 누락 경고를 중복 표시 | 일정의 연결을 경로 자료와 별개로 점검. 알려진 계획 도착지 유지, 다른 날짜 도시로 이동 경고 | 경로 없는 잘못된 출발지는 위반, 계획 도착 후 불필요한 경고 없음 |
| 좌석이 없는 장소의 휴식을 미확인으로만 표시 | 좌석 없음은 위반, 자료 없음은 미확인으로 구분 | 좌석 false인 휴식 항목 위반 |
| 잘못된 검색 입력을 공급자 장애 502로 표시 | 잘못된 쿼리/JSON은 400, 크기 초과는 413. 공급자 호출 없음 | GET 범위 초과·깨진 POST JSON·큰 요청 검사 |
| 설정 오타·잘못된 URL/검토자/알림으로 준비 상태가 통과하거나 API가 예외 발생 | origin 형식 검증, 기능 이름·UUID·HTTPS 알림·operations secret 검사. UUID 대소문자와 공백 정규화. 잘못된 설정은 readiness 실패 | 잘못된 설정 거부, 정상 설정 통과, origin 검사 예외 없음·대문자 UUID 역할 유지 |

범위에 맞는 타입·단위·브라우저·runtime 검사를 실행하며 최종 결과는 [검증 기록](VALIDATION.md)에 기록합니다. 자동 검사는 실제 SMTP/유료 API/물리 기기/독립 시설 확인을 대신하지 않습니다.
