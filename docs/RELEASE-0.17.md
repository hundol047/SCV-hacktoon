# 여행잇 0.17 — 이동 안내와 일정 공유

- 장소 사이에 이동 화살표를 표시합니다. 자동차·택시는 OSRM 경로 조회 성공 시 도로 예상 시간/거리를 표시하며 실시간 교통은 반영하지 않습니다. 실패하거나 도보·대중교통인 경우 기존 일정의 이동 배정 시간과 길찾기를 표시합니다. 소요 시간이 배정 시간을 넘으면 차이를 알리고 저장된 일정을 임의 변경하지 않습니다.
- 같은 장소에서 이어지는 휴식은 관광 항목에 합쳐 표시합니다.
- 출발지와 첫 장소가 직선 60km 이상 떨어져 있으면 첫 장소까지 차량 예상 시간, 시외버스 예약 링크, 열차 예약 링크, 도착 터미널 후보 검색 및 마지막 구간 길찾기를 제공합니다. 후보는 Nominatim 검색 결과이며 직행편이나 예약 가능 좌석을 보장하지 않습니다. 예약 화면의 도착 터미널을 확인해야 합니다.
- 공유 링크는 `/shared#v1=...`에 압축된 일정 사본을 담습니다. 수신자는 로그인 없이 볼 수 있습니다. 출발지, 장소 좌표, 인원, 방문 시간이 포함되며 계정·예산·개인 조건·변경 이력은 제외합니다. 사본은 원본 수정과 동기화되지 않으며 링크를 가진 사람은 열람할 수 있습니다. 압축 전후 크기를 제한하고 스키마를 검증합니다.
- Google 캘린더 버튼은 선택한 하루를 하나의 일정으로 추가하는 화면을 엽니다. 전체 일정 ICS는 장소별 방문·휴식 이벤트를 내보내며 Google/Apple/Outlook 등에서 가져올 수 있습니다. Google 계정 로그인과 최종 저장은 사용자가 캘린더에서 합니다.
- HTTP에서 공유/클립보드 API가 없어도 선택·복사 가능한 링크를 제공합니다. Android는 시스템 공유 창과 캘린더 파일 저장기를 사용합니다.

검증: 단위 테스트 215개, 웹 production 빌드, Android APK 빌드와 서명 확인. 데스크톱·모바일 브라우저 테스트는 경로·터미널 응답을 모의하여 공유 링크, 휴식 병합, 시간 차이 표시, 캘린더 파일, 잘못된 링크 및 조회 실패 처리를 확인합니다.

실제 EC2 배포, 실제 도로/터미널 응답, Google 계정에 최종 저장, Android 실기기 동작은 별도 확인이 필요합니다. 이번 변경은 Bedrock 인증·모델·AI 사용량 제한을 바꾸지 않습니다.
