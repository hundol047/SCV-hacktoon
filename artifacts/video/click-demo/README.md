# 보폭 실행 시연

- 영상: 보폭_클릭시연_관광지_호텔.mp4 (163.9초, 1920×1080, 30fps, H.264/AAC 무음).
- 최신 로컬 프로덕션 앱을 실제 조작하여 녹화했습니다. 외부 AI 응답이나 실시간 도로·예약 공급자 연결을 시연한 것은 아닙니다.
- 소개·마무리에는 사용자가 제공한 실제 화면을 사용했습니다. 라카이 샌드파인·컨피네스 오션 스위트 호텔 사진은 사용자 제공 실제 화면에서 동일 호텔의 사진 부분을 녹화용 로컬 캐시로 표시했습니다. 남항진해변과 가시연습지 사진도 사용자 제공 동일 장소 화면에서 캐시로 표시했습니다. 다른 외부 사진·지도는 대체 표시가 있을 수 있습니다.
- 한국어 자막은 영상에 포함되며 별도 SRT도 제공합니다. 유튜브 게시 자체는 수행하지 않았습니다.
- 재현: record-bopok-click.cjs → edit-bopok-click.py.
