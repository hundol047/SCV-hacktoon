# 보폭 실행 시연

- 영상: 보폭_실행시연_유튜브.mp4 (162.6초, 1920×1080, 30fps, H.264/AAC 무음).
- 최신 로컬 프로덕션 앱을 실제 조작하여 녹화했습니다. 외부 AI 응답이나 실시간 도로·예약 공급자 연결을 시연한 것은 아닙니다.
- 소개·마무리에는 사용자가 제공한 실제 화면을 사용했습니다. 본 녹화에서는 외부 사진이 로드되지 않는 경우 앱의 대체 표시가 나옵니다.
- 한국어 자막은 영상에 포함되며 별도 SRT도 제공합니다. 유튜브 게시 자체는 수행하지 않았습니다.
